# Actividad 3 - Juego Top-Down 2D - Unity

Este repositorio contiene el desarrollo de la **Actividad 3. Grupal. Top-Down completo**, realizada como parte del **Máster Universitario en Diseño y Desarrollo de Videojuegos - UNIR**.

---

- **Asignatura:** Desarrollo de Videojuegos I
- **Tipo de actividad:** Práctica grupal
- **Fecha de desarrollo:** Febrero de 2026

---

El objetivo de la actividad es aplicar de forma práctica los conceptos vistos en la asignatura, siguiendo buenas prácticas profesionales tanto en el desarrollo técnico como en la organización del proyecto.

## 🎮 Descripción del proyecto

El proyecto consiste en un **juego 2D con vista top-down**.

---

## 🛠️ Requisitos técnicos

- **Motor:** Unity
- **Versión de Unity:** `6000.3.1f1`
